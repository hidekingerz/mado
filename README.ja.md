# mado

[English](README.md)

**mado**（窓）は、ディレクトリ内の Markdown を読むためのターミナルリーダーです。プロジェクトのドキュメントやメモフォルダなどを対象にしています。Go で書かれており、[Bubble Tea](https://github.com/charmbracelet/bubbletea) と
[Glamour](https://github.com/charmbracelet/glamour) の上に構築されています。ファイルを閲覧しながらレンダリングし、ファイルツリー、タブ、検索、ダイアグラムでたどりやすくします。

![mado screenshot](docs/assets/screenshot.png)

## 機能

### 読む

- Glamour による**ターミナル内 Markdown レンダリング**
- **リーダー / ソースモード** — キー一つで、整形されたドキュメント表示とシンタックスハイライト付きの生 Markdown 表示を切り替えられます
- ソースビュー（および Markdown 以外のファイル）での**行番号表示**。vi の `:set nu` に相当します
- **Mermaid ダイアグラム** — ```mermaid ブロックをリーダービュー内でボックス文字のダイアグラムとして描画します。ブラウザは不要です
- **画像のインライン プレビュー** — PNG/JPEG/GIF ファイルをペインに収まるハーフブロックのピクセルアートとして表示します

### たどる

- カレントディレクトリを起点とする**サイドバーのファイルツリー**（遅延読み込み、折りたたみ可能。`a` で Markdown のみ表示と全ファイル表示を切り替え）。ツリーは表示中のファイルに追従します。ファイルを開いたりタブを切り替えたりすると、そのディレクトリが展開され、カーソルがそのファイルへ移動します
- **複数ファイルを開く** — ファイルごとに専用のタブが開きます
- **ファイル検索** — `/` で名前検索、`ctrl+f` で内容検索を、入力しながら実行します。内容ヒットは該当行までスクロールしてファイルを開きます。`node_modules` のようなディレクトリは除外され、除外リストは設定可能です
- **マウス対応** — ファイルをクリックして開く、タブをクリックして切り替える、`✕` をクリックして閉じる、両ペインでのホイールスクロール

### 他のツールと並べて使う

- **自動再読み込み** — `--watch` を付けると、開いているファイルがディスク上で変更されるたびに再レンダリングします。mado をペインに常駐させてライブビューとして使えます
- **リモートコマンド** — `mado --remote open FILE` は、新しいインスタンスを起動する代わりに、すでに画面上にあるインスタンスにタブを追加します
- **内容は表示されるだけで、実行されません** — 制御文字はターミナルにそのまま渡されず、キャレット記法で表示されます。閲覧中のファイルがクリップボードやウィンドウタイトル、カーソルを乗っ取ることはありません

### 自分好みにする

- **TOML 設定** — `~/.config/mado/config.toml`
- **キーバインドの設定変更** — すべての操作を再割り当てできます
- **設定パネル** — `,` を押すと、すべての設定をその場で編集できるパネルが開きます。変更は即座に反映され、コメントはそのままに設定ファイルへ1キーずつ書き戻されます
- **テーマのカスタマイズ** — Glamour スタイル（`auto`、`dark`、`light`、`dracula`、または任意のスタイル JSON）に加え、UI カラーとソースモード用ハイライトの `source_style`

## インストール

Linux、macOS、Windows 向けのビルド済みバイナリを
[リリースページ](https://github.com/hidekingerz/mado/releases)からダウンロードするか、Go でインストールします。

```sh
go install github.com/hidekingerz/mado@latest
```

または、ソースからビルドします。

```sh
git clone https://github.com/hidekingerz/mado.git
cd mado
go build -o mado .
```

## 使い方

```sh
mado                  # カレントディレクトリ以下の Markdown ファイルを閲覧
mado docs/            # docs/ を起点にサイドバーを表示
mado README.md a.md   # 起動時にファイルをタブで開く
mado --watch TASKS.md # ファイルの変更を自動で再読み込み
mado --remote open notes.md   # 実行中の mado にタブを追加
mado -style dracula   # Markdown テーマを上書き
mado -config my.toml  # 別の設定ファイルを使用
mado -version         # バージョンを表示
```

### 表示モード

ファイルの見方は2通りあり、`m` で切り替えます。

- **リーダー**（既定）— Markdown を整形されたドキュメントとしてレンダリングします。見出しの記号（`##`）は隠され、レベルは色、下線、斜体で区別されます。
- **ソース** — 生の Markdown テキストで、構文自体を確認できます。

![reader and source modes](docs/assets/modes.png)

起動時のモードは、設定ファイルの `default_mode = "source"` で指定できます。

ソースビュー（および Markdown 以外のテキストファイル。これらは常にソースとして表示されます）では、`n` で行番号を切り替えます。vi の `:set nu` と同じです。折り返された継続行は空のガター（余白）になるので、行番号は折り返しではなくファイル本来の行に対応します。

### Mermaid ダイアグラム

リーダーモードでは、フェンス付きの ```mermaid ブロックが、元のソースの代わりにボックス文字で構成されたダイアグラムとして描画されます。フローチャート、シーケンス図、クラス図、状態遷移図、ER 図などに対応しており、[mermaid-ascii](https://github.com/pgavlin/mermaid-ascii) を利用しています。ソースモードでは、ブロックは記述されたとおりに表示されます。描画できないダイアグラムや、コンテンツペインより幅の広いダイアグラムはソース表示にフォールバックするので、何かが欠けたり折り返されたりすることはありません。フローチャートのエッジラベルは `A -->|yes| B` の形式で書くと最もきれいに描画されます。認識されるのは行頭に書かれた ```` ```mermaid ```` というフェンスだけです。リストの中でインデントされたもの、`~~~` フェンス、言語指定の後に余計な語が付いたものは認識されません。また、CRLF 改行のファイルはソースとして表示されます。この機能をオフにするには、`[general]` の下で `mermaid = false` を設定します。

### 検索

`/` を押すと、コンテンツペインの上に検索パネルが開き、ファイルを名前で検索します。`ctrl+f` は内容検索用にパネルを開きます。結果は入力しながら表示されます。`tab` はクエリを保持したまま2つの検索対象を切り替え、`↑`/`↓` は結果間を移動し、`enter` は選択中のファイルを開き、`esc` はパネルを閉じます。内容ヒットは、該当行までスクロールしてファイルを開きます。入力した文字はクエリに入るため、プロンプトが開いている間は `q` や `?` は動作しません。`ctrl+c` は引き続き終了に使えます。

マッチングは単純な部分文字列一致です。大文字を含まないクエリでは大文字小文字を区別せず、ルートからの相対パスに対して照合するので、`docs/plan` のようにディレクトリ名でも絞り込めます。検索が対象とする範囲はサイドバーに表示されうるものと同じです。`a` で全ファイル表示に切り替えていない限り Markdown ファイルのみが対象で、`show_hidden` がオンでない限りドットファイルは対象外です。バイナリファイルと8MBを超えるファイルは内容検索の対象外で、ヒット数は1000件で打ち切られます。

検索する価値のないディレクトリは、設定の `[search] exclude` で除外できます。既定値は `node_modules`、`.git`、`vendor`、`dist`、`build`、`target` です。スラッシュを含まないパターンは、どの深さの名前にもマッチします（`node_modules`、`*.log`）。スラッシュを含むパターンは、ルートからの相対パスにマッチします（`docs/drafts`）。このキーを設定すると既定のリストが置き換わるので、`exclude = []` とするとすべてが検索対象になります。

### マウス

- サイドバーのファイルをクリックすると開きます。ディレクトリをクリックすると展開・折りたたみします。
- タブをクリックすると切り替わります。タブの `✕` をクリックすると閉じます。
- スクロールホイールは、ポインタの下にあるペインをスクロールします。

### 自動再読み込み

既定では、ファイルは `r` / `F5` を押したときだけ再読み込みされます。`--watch`（または設定の `watch = true`）を付けると、mado は開いているファイルとサイドバーのディレクトリを監視し、変更があるとすぐに再読み込みします。スクロール位置は保持されます。ステータスバーの `[WATCH]` は、この機能がオンであることを示します。

これにより、mado をライブダッシュボードとして使えます。別プロセスが書き換え続けるプランやログファイルを開いたままにしておけば、ペインがそれに追従します。短時間に連続して発生する書き込みはまとめられるので、一連の保存によるコストは1回の再読み込みで済みます。

ファイルの内容は表示されるだけで、実行されることはありません。制御文字はターミナルに渡されるのではなく、キャレット記法（エスケープなら `^[`）で描画されます。そのためファイルがクリップボードを書き換えたり、ウィンドウタイトルを書き換えたり、画面表示を上書きするためにカーソルを動かしたりすることはありません。これはサイドバーのファイル名についても同様です。ANSI カラー付きのログファイルが、色ではなくエスケープコードのテキストとして表示されるのはこのためです。

### リモートコマンド

実行中の mado は他のプロセスからのコマンドを受け付けます。スクリプトやエディタのフック、ターミナルマルチプレクサのプラグインが、新しいビューアを開くことなくファイルを目の前に表示できます。

```sh
mado --remote open docs/plan.md    # タブを追加（すでに開いていれば切り替え）
mado --remote focus docs/plan.md   # そのファイルのタブに切り替え。開いていなければ失敗
```

実行中のインスタンスがない場合、`--remote open` はそれらのファイルとともに新しいインスタンスを起動します。そのため無条件に使っても安全です。`--remote focus` は既存のインスタンスでファイルを開くことは一切なく、すでに開いているものの間を移動するだけです。

各インスタンスは、pid にちなんだ名前の Unix ソケットで待ち受けます。場所は `$XDG_RUNTIME_DIR/mado` です（`XDG_RUNTIME_DIR` が未設定の場合は、システムの一時ディレクトリ配下の専用ディレクトリになります）。コマンドは応答する最も新しく起動したインスタンスに送られます。両端を1つのインスタンスに固定するには、`MADO_SOCKET` にソケットパスを設定します。

```sh
MADO_SOCKET=/tmp/mado-notes.sock mado notes/     # このインスタンスに…
MADO_SOCKET=/tmp/mado-notes.sock mado --remote open notes/today.md   # …ファイルが渡る
```

このソケットディレクトリは信頼境界です。コマンドが開くものは何であれ、あなたの権限で開かれます。mado はこのディレクトリを非公開として作成し、すでに存在する場合は、それが自分の所有であり他のユーザーが書き込めないことを確認します。`XDG_RUNTIME_DIR` が未設定の共有マシンでは、ディレクトリ名が予測可能なため、誰かが先にディレクトリを作ってソケットを仕込む可能性があるからです。チェックを通らないディレクトリの場合、そのインスタンスではリモートコマンドがオフになり、理由が標準エラーに1行出力されます。それ以外の mado の機能はすべて通常どおり動作します。

### 設定

`,` を押すと、`config.toml` のすべてのキーをテーブルごとに一覧表示する設定パネルがコンテンツペインの上に開きます。`↑`/`↓`（または `k`/`j`）で項目間を移動し、フッターには選択中の項目の説明と既定値が表示されます。編集方法は値の種類によって異なります。`enter` または `space` はスイッチを切り替え、`←`/`→` は選択肢を切り替え、`enter` はテキスト・数値・リスト用のインラインプロンプトを開き（`enter` で適用、`esc` でキャンセル）、キーバインドの場合は `enter` を押すと次に押したキーを（`esc` を含めて）そのまま取り込みます。`backspace` はその操作の最後のキーを削除します。`esc` または `,` でパネルを閉じます。`ctrl+c` は引き続き終了に使えます。

変更はその場で反映されます。色は塗り直され、新しいスタイルは開いているタブを再レンダリングし、ツリーは再読み込みされ、監視は開始または停止し、再割り当てされたキーは次の入力から有効になります。同時に設定ファイルへも即座に書き込まれます。書き込まれるのはそのキーだけなので、手書きの設定ファイルもコメントや順序が保たれます。無効な値（`#RRGGBB` や `0`〜`255` の形式でない色、他の操作がすでに使っているキーなど）は拒否され、ステータスバーに注記が表示されて何も変更されません。

### 既定のキーバインド

| キー                | 操作                             |
| ------------------ | -------------------------------- |
| `↑`/`k`, `↓`/`j`   | カーソル移動 / スクロール         |
| `enter`/`l`        | ファイルを開く / ディレクトリを展開 |
| `esc`/`h`          | サイドバーにフォーカス            |
| `tab`/`]`          | 次のタブ                          |
| `shift+tab`/`[`    | 前のタブ                          |
| `x`/`ctrl+w`       | タブを閉じる                      |
| `b`/`ctrl+b`       | サイドバーの表示切り替え          |
| `ctrl+d`/`ctrl+u`  | 半ページ下 / 上にスクロール       |
| `g`/`G`            | 先頭 / 末尾へ移動                 |
| `r`/`F5`           | ツリーと現在のファイルを再読み込み |
| `m`                | リーダー / ソースモードの切り替え |
| `a`                | 全ファイル表示 / Markdown のみ    |
| `n`                | 行番号の切り替え（ソース）        |
| `/`                | ファイル名で検索                  |
| `ctrl+f`           | ファイル内容で検索                |
| `,`                | 設定                              |
| `?`                | ヘルプ                            |
| `q`/`ctrl+c`       | 終了                              |

## 設定

mado は `$XDG_CONFIG_HOME/mado/config.toml`（既定では
`~/.config/mado/config.toml`）を読み込みます。すべてのキーは省略可能で、未設定の値は既定値にフォールバックします。設定パネル（`,`）はこのファイルをその場で編集します。全項目の注釈付きリファレンスは [`config.example.toml`](config.example.toml) を参照してください。

```toml
[general]
watch = false              # true = ファイル変更時に自動で再読み込み
mermaid = true             # ```mermaid ブロックをリーダービューに描画

[theme]
style = "dracula"          # glamour のスタイル名、またはスタイル JSON へのパス
accent_color = "#7C6AEF"
dir_color = "#89B4FA"      # サイドバーのディレクトリ名
file_color = "#FFFFFF"     # サイドバーのテキストファイル（既知のバイナリは減光表示）

[sidebar]
width = 32
show_all_files = false     # true = Markdown 以外のファイルも一覧表示
show_hidden = false

[search]
exclude = ["node_modules", ".git", "vendor", "dist", "build", "target"]

[keys]
quit = ["q", "ctrl+c"]
open = ["enter", "l"]
next_tab = ["tab", "]"]
# … config.example.toml にあるその他の操作
```
